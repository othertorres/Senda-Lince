# Senda Lince

Copia recuperada de la edición pública BETA LOCAL v5.5 y entorno de pruebas local.

```sh
python3 scripts/verify_snapshot.py
python3 scripts/serve_staging.py
```

Abrir `http://127.0.0.1:4173` en el equipo que ejecuta el servidor.
Los datos de este origen están separados de los de la web pública.

- Código servido: `public/` (sin compilación ni dependencias).
- Trabajo comercial: `feature/saas-security`.
- Copia publicada recuperada: `recovery/published-v5.5-2026-10-21`.
- [Entornos, recuperación y límites de la verificación](docs/entornos-y-recuperacion.md).

Producción continúa en https://senda-lince.netlify.app/.
No se ha modificado su despliegue ni se han configurado cobros.
